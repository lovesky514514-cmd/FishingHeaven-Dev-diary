## 2026.08.18 开发日志
 1. **主角与美术方向重构**
   - 主角由原来的哥布林正式更换为现有素材中的女性精灵角色。
   - 保留现有精灵商人素材作为主要 NPC。
   - 整理现有场景素材，确定环境变化路线：
     **明亮正常 → 冷灰 → 阴暗/暴雨 → 红色异常**。
   - 后续恐怖变化优先基于现有素材进行阶段切换。

2. **核心钓鱼玩法重新确定**
   - 保留“先听节奏，再进行操作”的主要设计。
   - 单次钓鱼流程调整为：
     **抛竿 → 节奏预听 → 缩圈判定 → 完整节奏结束 → 钓鱼结算**。
   - Perfect / Good / Miss 只影响本次表现与 Fever 获取。
   - Miss 不再中断整轮钓鱼流程，也不会立即让鱼逃走。
   - 鱼类后续采用数据驱动 Rhythm Pattern 系统，不同鱼拥有不同 BPM、节奏型和难度。

3. **Fever 系统重新设计**
   - 玩家通过缩圈节奏判定持续积累 Fever 能量。
   - Fever 能量达到 100% 时不立即打断当前钓鱼。
   - 当前 Fishing Segment 完整结束后才进入 Fever Time。
   - Fever Time 定位为奖励阶段，而不是第二套高难度玩法：
     大量鱼获、水花、快速缩圈和高密度反馈共同形成爆发爽点。
   - 正常钓鱼负责“听、记、判断”，Fever 负责释放和奖励。

4. **Game in Game / Meta 架构确定**
   - 《钓鱼天国》不再只是单层钓鱼游戏，而是采用“游戏中的电脑游戏”结构。
   - 玩家最开始直接进入《钓鱼天国》，并不知道它只是角色电脑中的一个程序。
   - 玩家可以一直留在钓鱼游戏中，不强制进入剧情。
   - 主动关闭游戏后进入伪 Win 桌面。
   - 后续继续探索时，可出现：
     **Fishing Heaven → Desktop A → Desktop B → Reality**
     的多层嵌套结构。
   - 通过文件夹、日志、异常文件和无法真正关闭的窗口逐渐揭示真实世界。
